# Code of Conduct

DyKnow is meant to be a respectful, technically rigorous project.

## Expected Behavior

- Be respectful in code review, issues, and discussions.
- Keep feedback specific, technical, and actionable.
- Assume good intent, then ask for clarity when something is ambiguous.
- Leave the repo in a better state than you found it.

## Unacceptable Behavior

- Harassment, threats, discrimination, or hateful conduct.
- Doxxing, intimidation, or sexualized language.
- Repeated bad-faith disruption of reviews, issues, or discussions.
- Publishing private information that was not intentionally shared publicly.

## Enforcement

Maintainers may edit or remove content, close conversations, reject
contributions, or block participants whose behavior violates this code.

## Reporting

If discretion is needed, report conduct issues through the repository owner's
GitHub contact information instead of a public issue.
