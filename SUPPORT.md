# Support

Use GitHub Issues for bug reports, feature requests, and documentation gaps.

Before opening an issue:

- read [README.md](README.md) for repo layout and commands
- read [CONTRIBUTING.md](CONTRIBUTING.md) for workflow and review expectations
- run `npm ci`, `npm run lint`, `npm test`, and `npm run build` for code issues

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
